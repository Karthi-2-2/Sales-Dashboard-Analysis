# Sales Dashboard

This project was created as part of my Data Analyst Internship Task 3.

Using Tableau, I developed an interactive sales dashboard to study sales performance across different categories, payment methods, customer segments, and shopping malls.

## Tools Used
- Tableau
- Excel Dataset

## Dashboard Features
- Sales Overview
- Customer Analysis
- Payment Method Analysis
- Category-wise Sales
- Mall-wise Performance

## Key Findings
- Clothing category generated the highest sales.
- Female customers contributed more to total sales.
- Cash was the most frequently used payment method.
- Mall of Istanbul recorded the highest revenue.
